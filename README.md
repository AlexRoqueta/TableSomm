# Water Grill TableSomm deploy package

This folder is ready for static deployment.

## Netlify
- Create a new site from drag-and-drop or Git.
- Upload this folder or connect the repo.
- Publish directory: `.`

## Vercel
- Import the folder as a project.
- Framework preset: Other.
- No build command required.
- Output directory: `.`

## Included
- `index.html` — standalone app with embedded logo and seeded menu/wine data
- `netlify.toml` — basic Netlify config
- `vercel.json` — basic Vercel config
